# Mindfullearning (`mindful-new`) — Project & Workflow Rules

- **Stack:** pnpm workspace (`backend/` Express + Mongoose ES modules, `frontend/` Vue 3 + Vuex + Vuetify, Vitest, Playwright).
- **Phase 1 vs. Phase 2 Scope:** Keep Phase 1 focused on wrap-up, bug fixes, and test/coverage gates. Route unquoted Phase 2 requests (AI chatbot, one-way SMS, personalized APL kits, auto-diplomas, question bank, content-sync expansions) to `1. Parkeringsplats (Idéer)` (`parking-lot`).
- **Estimation Rule:** Every scoped feature ticket must include a hidden-work checklist (permissions/roles, empty/loading/error states, validation/edge cases, responsive layout, tests, demo) and multiply raw gut hours by **2.2x** for `Uppskattad tid (tim)`.
- **Kanban Columns:** `1. Parkeringsplats (Idéer)`, `2. Specificerad & Offertad`, `3. Godkänd`, `4. Pågående` (WIP: 2), `5. Redo för demo`, `6. Klar`.
- **Billing Categories:** `Etapp 1 (Avtal)`, `Etapp 2 (Betald)`, `Bugg / Garanti`.
